# Generador de Paleta de Colores Gratis

Aplicación web gratuita para **crear paletas de colores aleatorias** y armoniosas. Ideal para diseñadores y desarrolladores.

## ✨ Características

- Genera paletas de **5 colores** armónicos.
- **Bloquea** colores individuales (🔒).
- Copia códigos **HEX** y **RGB** con un clic.
- Atajo de teclado: **barra espaciadora** para regenerar.
- Detección automática de contraste de texto.

## 🚀 Uso

1. Pulsa **"Generar Paleta"** o la barra espaciadora.
2. Bloquea los colores que te gusten.
3. Copia los códigos HEX con un clic.
